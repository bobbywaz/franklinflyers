## 2024-05-18 - Plaintext Password Storage Mitigated with Secure PBKDF2 Hashing
**Vulnerability:** The admin password was previously stored in plaintext within the application's configuration database, putting the system at risk of full compromise if the database was leaked or accessed by an unauthorized entity. A secondary issue existed where timing attacks were possible during password comparisons using `!=`.
**Learning:** Initializing default configurations with plaintext passwords and comparing them linearly leaves the system inherently vulnerable to simple compromise and timing attacks.
**Prevention:** Always implement strong, irreversible password hashing algorithms like PBKDF2, bcrypt, or Argon2 before storing credentials. In Python, use `hashlib.pbkdf2_hmac` combined with a cryptographically secure random salt generated by `secrets.token_hex`. Also, use `secrets.compare_digest` for secure string comparison to prevent timing attacks.
