## 2024-05-18 - Admin Password Stored in Plaintext
**Vulnerability:** The application stored the admin password (`"changeme"`) in plaintext in the database via the `Configuration` table during `startup_event`, and verified passwords using insecure string equality comparison (`!=`), exposing the system to potential timing attacks and credential theft.
**Learning:** Initializing default configuration keys during application startup must inherently use secure hashing (like PBKDF2 with a salt) just like user registration flows. When retrofitting a hash into an existing plaintext field, `verify_password` must include a secure structural check (e.g. `len() == 97` and salt delimiter `$`) to differentiate plaintext legacy values and fall back securely to `secrets.compare_digest`.
**Prevention:** Always use a standard derivation function (`hashlib.pbkdf2_hmac` + `secrets.token_hex`) for new sensitive configuration secrets. Never use standard `==` or `!=` equality checks on sensitive tokens; strictly enforce `secrets.compare_digest` to prevent early-exit timing vulnerabilities.
