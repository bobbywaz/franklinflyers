## 2026-03-05 - Restore Focus Indicators
**Learning:** Tailwind CSS resets like `focus:outline-none` and `focus:ring-0` commonly obscure focus states, leading to poor keyboard navigation accessibility for checkboxes and links.
**Action:** Always replace these resets with visible focus indicators using `focus-visible:ring-2` to ensure keyboard accessibility while preventing unwanted mouse-click outlines.
