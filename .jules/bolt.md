## 2024-10-11 - N+1 Lazy Loading Queries in SQLAlchemy Context Builders
**Learning:** Found N+1 query issue in `_build_home_context` and `_build_admin_context` when fetching `Run` model and lazily evaluating relationships (e.g., `deals`, `best_store`, `published_stores.dataset`). When evaluating a list like `latest_run.published_stores` without eager loading, SQLAlchemy performed an extra query for every single store dataset.
**Action:** Used `joinedload()` for scalar relationships (e.g., `best_store`) and `selectinload()` for collection relationships (e.g., `deals`, `published_stores`) to avoid Cartesian product explosions and N+1 query overhead. Chained joins for nested relationships (e.g., `selectinload(Run.published_stores).joinedload(PublishedSnapshotStore.dataset)`).
