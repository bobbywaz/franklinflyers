## 2026-10-10 - Fix N+1 query problems in context builders
**Learning:** In this codebase's architecture, querying the `Run` model without explicitly eagerly loading related objects like `best_store`, `deals`, and `published_stores` leads to N+1 lazy loading queries in context builders (`_build_home_context`, `_build_admin_context`). This severely impacts performance, especially for collection relationships.
**Action:** Always use SQLAlchemy loader options when fetching a model that requires accessing its relationships later. Use `joinedload()` for scalar relationships (e.g., `best_store`) and `selectinload()` for collection relationships (e.g., `deals`, `published_stores`). Chain joins for nested relationships (e.g., `selectinload(Run.published_stores).joinedload(PublishedSnapshotStore.dataset)`).
