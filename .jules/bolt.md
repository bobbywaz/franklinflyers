## 2024-05-24 - Eager Loading with joinedload prevents N+1 Queries
**Learning:** When querying the `Run` model in `app/main.py`'s context builders (`_build_home_context`, `_build_admin_context`), iterating over related objects like `best_store`, `deals`, and `published_stores` in templates or Python loops triggers severe N+1 lazy loading queries. SQLAlchemy's `joinedload` can be chained, such as `joinedload(Run.published_stores).joinedload(PublishedSnapshotStore.dataset)`, to load deeply nested relationships in a single operation.
**Action:** Always inspect FastAPI route handlers or context builders that fetch a primary model (like `Run`) and ensure all relationships accessed in the downstream Jinja templates or serialization steps are eagerly loaded using `.options(joinedload(...))` to minimize database roundtrips.
