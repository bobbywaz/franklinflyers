## 2024-06-21 - N+1 Lazy Loading Queries in Admin and Home Views
**Learning:** Querying the `Run` model in SQLAlchemy context builders (`_build_home_context`, `_build_admin_context`) results in significant N+1 lazy loading queries for its relationships (`deals`, `best_store`, `published_stores`). Measuring an in-memory db with a MockQuery counting cursor events showed 4 queries for the Home context and 79 for Admin context when rendering 100 dummy deals.
**Action:** When working with SQLAlchemy queries that fetch parent models and then iterate over children in views, explicitly eagerly load relationships (`joinedload`) to prevent N+1 queries. Using `joinedload` on relationships like `deals`, `best_store`, and chaining it on nested structures like `published_stores.dataset` reduced the cursor events drastically to 2 and 1 queries respectively.
