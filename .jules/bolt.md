## 2024-05-18 - SQLAlchemy Context Builder N+1 Query Optimization
**Learning:** In SQLAlchemy, executing multiple scalar and list relationships across lists of entities in loops (e.g. iterating over all scrapers to fetch latest_attempt, latest_success, active_dataset) triggers massive N+1 query patterns. Even when iterating in Python, if relationships aren't eagerly loaded, individual queries fire.
**Action:** Use `selectinload` (for collections) and `joinedload` (for scalars) when querying complex models like `Run`. For loop-based N+1 lookups on disjoint tables like `StoreDataset`, use `sqlalchemy.func.max` in subqueries and `.join()` to fetch exactly the latest state for all entities simultaneously, transforming O(N) database trips into O(1) bulk fetch and dict-lookups.
