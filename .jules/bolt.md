## 2026-10-17 - Optimize N+1 queries in SQLAlchemy context builders
**Learning:** When querying the `Run` model in SQLAlchemy context builders (e.g., `_build_home_context`, `_build_admin_context`), explicitly loading related objects is critical to prevent N+1 lazy loading queries. Using `joinedload()` for scalar relationships (e.g., `best_store`) and `selectinload()` for collection relationships (e.g., `deals`, `published_stores`) avoids Cartesian product memory explosions. For nested relationships, chain joins appropriately (e.g., `selectinload(Run.published_stores).joinedload(PublishedSnapshotStore.dataset)`).
**Action:** Always use `.options()` with appropriate eager loading strategies when fetching models that will have their relationships accessed later in the same request or context builder.
