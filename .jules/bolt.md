## 2024-05-24 - Intercepting and optimizing N+1 Queries in SQLite/FastAPI
**Learning:** To accurately benchmark and demonstrate N+1 query performance improvements in an in-memory SQLite setup (where latency differences are hard to measure), use SQLAlchemy's `event.listen(engine, 'before_cursor_execute')` to intercept and count the exact number of queries executed. Furthermore, when querying the `Run` model in SQLAlchemy context builders (e.g., `_build_home_context`, `_build_admin_context`), explicitly load related objects to prevent N+1 lazy loading queries. Use `joinedload()` for scalar relationships (e.g., `best_store`) and `selectinload()` for collection relationships (e.g., `deals`, `published_stores`).
**Action:** Proactively apply `joinedload` and `selectinload` where relational models are rendered in templates, and rely on query interception to prove optimizations.
